What apps can do

Apps cannot load anything from the web directly. They ask Steed with fetch("steed://" + location.host + "/api/fetch?url=…") for web data (no cookies), and /api/tabs, /api/history and /api/bookmarks. Each follows Agents → Access & Permissions → Local pages (Never by default). Links open in normal tabs.
