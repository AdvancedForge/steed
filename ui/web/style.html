Shared styling for Steed pages. Individual pages can add their own CSS.

Appearance changed in another window. Reload saved settings before applying.

Light or dark

Applies at once, to the browser and Steed's pages.

Your own colours and CSS (advanced)

Theme colors

Choose your own background, text, cards and feedback colors. Custom CSS takes precedence.

Use tokens such as --bg, --surface, --ink, --muted and --accent, or CSS selectors. Pages remain offline; external fonts and images cannot be loaded through this stylesheet. Custom HTML can override inherited styling.

CSS reference for users and agents

Change a palette field for colors, or use CSS selectors for a particular page. Apply style saves to the selected scope.

Agents: use steed_start_page_capabilities, then steed_start_page_propose with page=style and mode=theme. The user reviews the exact changes and chooses a profile before applying them. Existing browser/data permissions do not silently authorize a theme change.

Browser colours, one by one (advanced)

Every colour of the tabs, toolbar, menus and hover cards. Automatic colours follow the theme, or the New Tab photo when Match the background is on. Pick a colour to fix it; the others still follow along.

Keep these colours fixes every colour as it is now, so a new photo no longer changes them. Apply style to save.

Tabs & toolbar

Where tabs sit and how they, the toolbar and browser text look. These apply to every window and profile, and saved layouts remember them.

Browser bars

The address-bar menu button always opens General, Profile, Tabs, View, Cookies and Agents. Ctrl+Shift+M restores or hides the top menu.

Light and page

Steed's look: the page floats as a card in light that takes the site's colour. How much moves is in Settings → View → Motion and light.

Page loading

Progress is Qt WebEngine’s estimate for the selected tab. The indicator clears when loading finishes or stops.

This replaces other profiles’ appearance overrides. It does not copy their pages, images, history or accounts.
